# Me To You Designs — Balloon Quote Calculator

A mobile-first, browser-based balloon quoting app inspired by the feature set of Quote Your Balloons, but with original Me To You Designs branding and workflow.

## Included
- Dashboard
- Quick quote calculator
- Detailed itemised calculator
- Helium cost calculator
- Saved quotes with search/status filtering
- Branded quote preview
- Print / Save as PDF through the browser print dialog
- Deposit and balance calculation
- Business settings and terms
- Local browser storage (no server required)
- Mobile responsive layout

## Run
Open `index.html` in a browser. For best results, serve the folder with any simple local/static web server or deploy it to GitHub Pages.

## Data
Quotes and settings are stored in the browser's localStorage. This version does not include authentication or cloud sync.
